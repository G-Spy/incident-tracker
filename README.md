# Ticket Tracker API

## Project Overview

A simple REST API for managing support tickets.

The project aims to help a support team create, track, update and manage customer support tickets in one system.

## Business Need

Support teams need a simple way to manage customer issues and quickly access ticket information.

The objective is to provide a centralized system where support agents can create, view, update and manage tickets.

## Scope

### In Scope

- Create a ticket
- List all tickets
- View a ticket
- Update ticket status
- Assign a ticket to a user
- Add a comment to a ticket
- Store ticket data in PostgreSQL
- Provide REST API endpoints
- Test the API with Postman
- Document the API with Swagger

### Out of Scope

- Authentication
- Email notifications
- Frontend application
- Complex user management
- Microservices
